منظومة مؤسسية سحابية متقدمة (Enterprise Full-Stack System) لإدارة عمليات التأمين الصحي والضمان الاجتماعي للمنشآت والمستفيدين والمهن الحرة.

---

### ✨ المميزات الرئيسية (Key Features)
1. **تطبيق هاتف متعدد الأدوار (Multi-Role Mobile App):**
   - **بوابة الإدارة المركزية (Central Admin):** إدارة الأقسام والمستخدمين والصلاحيات.
   - **بوابة الاستقبال والعملاء:** تسجيل المشتركين وإصدار البطاقات التأمينية.
   - **بوابة التفتيش والرقابة الميدانية:** تفتيش المنشآت وتوثيق الالتزام وضبط المخالفات.
   - **بوابة الاشتراكات والتحصيل:** متابعة الفواتير ودفعات المنشآت وحساب نسب التأمين.
   - **بوابة المنافع والتعويضات:** إدارة مطالبات العلاج، الرعاية الصحية، وتعويضات إصابات العمل.
   - **بوابة المشتركين الذاتية:** الاستعلام عن البطاقة، تغطية المستشفيات، وتحميل المستندات.
2. **توليد بطاقات وتقارير PDF:** تصدير وطباعة بطاقات المشتركين والتقارير المالية بصيغة PDF فورياً.
3. **خلفية برمجية متطورة (Node.js Backend):**
   - نظام مصادقة آمن وتشفير كلمات المرور (bcrypt & JWT).
   - تحكم بالوصول المبني على الأدوار (Role-Based Access Control - RBAC).
   - سجل تدقيق العمليات (Comprehensive Audit Trail & Logs).
   - ربط سحابي بقاعدة بيانات PostgreSQL (Neon Cloud DB) و Firebase Firestore.

---

### 🛠️ البنية التقنية (Tech Stack)
- **Mobile Client:** Flutter (Clean Architecture)
- **Backend API:** Node.js, Express.js
- **Databases:** PostgreSQL (Neon DB) & Firebase Firestore
- **Security:** JWT, bcrypt, CORS, Environment Isolation

---

### 🚀 طريقة التشغيل (How to Run)
```bash
# تشغيل خادم الباك إند
cd backend
npm install
node server.js

# تشغيل تطبيق الفلاتر
cd ../insurance_app
flutter pub get
flutter run
```
